# MedikTest Collector — инструкция клиента

## Запуск готовой Windows-версии

1. Скачайте ZIP-архив, но не запускайте программу прямо из него.
2. Создайте короткую папку `C:\MedikTest`.
3. Щёлкните по архиву правой кнопкой → «Извлечь все» и укажите `C:\MedikTest`.
4. Откройте `C:\MedikTest\MedikTest-Collector`.
5. Запустите `MedikTest-Collector.exe`.
6. Не закрывайте появившееся консольное окно: пока оно открыто, программа работает.
7. В браузере автоматически откроется локальная панель.
8. Введите логин и пароль отдельного аккаунта тренажёра и нажмите «Сохранить».

Короткий путь `C:\MedikTest` нужен из-за ограничения Windows на длину имён
вложенных файлов Chromium. Если при создании папки Windows запросит подтверждение,
разрешите операцию.

URL тренажёра уже настроен. Пароль хранится только до закрытия программы.

Python, командная строка и дополнительная установка браузера не нужны — всё необходимое включено в программу.

Программа не подписана коммерческим сертификатом. Если Windows покажет окно SmartScreen, проверьте имя файла и контрольную сумму, затем выберите «Подробнее» → «Выполнить в любом случае».

## Настройка сбора

Укажите:

- тип материалов;
- ориентировочное количество тестов;
- ориентировочное количество ситуационных задач;
- проверочный запас в процентах;
- максимальное число попыток;
- максимальное число выдач;
- максимальное время работы.

Если выбран только один тип материалов, ориентир второго типа не требуется.

## Разрешения

«Разрешить создавать новые попытки» позволяет программе открыть новую попытку, если доступных материалов недостаточно.

«Разрешить выбирать ответы и завершать попытки» необходимо для получения правильных ответов. Без него программа работает в режиме чтения, а материалы с нераскрытыми ключами помечаются как незавершённые.

Оба разрешения относятся только к текущему запуску.

## Управление

- «Пауза» приостанавливает обработку после текущего безопасного шага;
- «Продолжить» возобновляет сбор;
- «Остановить» корректно завершает текущий запуск;
- после перезапуска программы незавершённый запуск можно продолжить после повторного ввода пароля.

## Результат

Программа создаёт одну Excel-книгу только с готовыми материалами и подтверждёнными ключами:

- `Tests` — одна строка на тест: номер, вопрос, правильный ответ и три неверных ответа;
- `exercise_rows`, `questions`, `answers` — полные ситуационные задачи.

Каждая задача хранится целиком в `exercise_rows`, её вопросы связаны через `exercise_id`, а варианты и правильность — через `question_id`.
Раскрываемые после шага результаты обследований и диагноз сохраняются в
`questions.text_after`. ID ответа имеет вид `<question_id><номер ответа>`.

Если в дополнительной информации есть изображения, в `text_after` записываются
их исходные имена, например `table_101668019967.png`. Сами изображения не
встраиваются в Excel: кнопка «Скачать изображения ZIP» создаёт отдельный архив с
папкой `images`, где файлы имеют точно такие же имена. Архив относится к тому же
режиму выгрузки: весь банк для общего документа или только текущий запуск для
нового документа.

Режим «Обновить общий документ» выгружает весь накопленный банк. Режим «Создать новый документ» выгружает только заданное количество уникальных материалов текущего запуска.

JSON содержит те же готовые материалы, статистику, перечень изображений и
отдельный перечень незавершённых записей.

В режиме «Обновить общий документ» выгрузка содержит полный накопленный банк на момент завершения выбранного запуска. В режиме «Создать новый документ» выгружаются только материалы текущего запуска. В JSON также есть `run_delta` — отдельный список новых и изменённых материалов этого запуска.

Повторный запуск сохраняет прежние ID, не создаёт дубли и фиксирует новые или изменённые материалы.

## Очистка и проверка актуальности

В разделе «Очистка и актуальность» можно отдельно посмотреть:

- материалы, подтверждённые текущим запуском;
- материалы общего банка, которые в этом запуске не встретились;
- дату последней встречи и общее количество появлений материала.

Кнопка «Скачать отчёт Excel» создаёт отдельный файл проверки актуальности. Основной единый Excel при этом сохраняет согласованную структуру из пяти листов.

Статус «Не проверен в запуске» не означает, что материал удалён из источника. Программа не удаляет такие материалы автоматически. Подтверждать удаление автоматически можно только при наличии официального полного списка идентификаторов.

Во время длительного сбора окно программы можно свернуть. Не закрывайте консольное окно и не выключайте компьютер. Если программа или Windows перезапустились, запуск появится со статусом «пауза»: повторно введите логин и пароль и нажмите «Продолжить».

## Где хранятся данные

В готовой Windows-версии база и выгрузки находятся в:

```text
%LOCALAPPDATA%\MedikTest
```

Эту папку рекомендуется периодически копировать в резервное место: в ней находится накопленный каталог и история запусков. Логин и пароль в ней не сохраняются.

## Если панель не открылась автоматически

1. Не закрывая программу, откройте Chrome или Edge.
2. Перейдите по адресу `http://127.0.0.1:8765`.
3. Если адрес не открывается, убедитесь, что не запущена вторая копия программы, и запустите `MedikTest-Collector.exe` ещё раз.

## Проверка полученного файла

Рядом с архивом передаётся файл `MedikTest-Collector-Windows.zip.sha256`. Контрольная сумма позволяет убедиться, что архив не повредился при передаче.

## Ограничение полноты

Если тренажёр не предоставляет официальный полный список идентификаторов, доказать абсолютный охват невозможно. Программа показывает ориентир, фактически найденное количество, проверочный объём и причину остановки.
