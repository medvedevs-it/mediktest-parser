# MedikTest Collector

Windows-программа для повторяемого сбора тестов и ситуационных задач из официального тренажёра ФМЗА по специальности «Лечебное дело».

## Возможности

- отдельный сбор тестов, ситуационных задач или обоих типов;
- ориентиры известного банка отдельно по каждому типу;
- дополнительный проверочный объём после достижения ориентира;
- повторы не останавливают сбор;
- ограничения по времени, числу выдач и попыток;
- пауза, продолжение, мягкая остановка и восстановление после перезапуска;
- SQLite-каталог, дедупликация и версии изменений;
- отдельные разрешения на создание и завершение попыток;
- полный кейс: условие, разделы, вопросы, варианты и правильные ответы;
- единая Excel-выгрузка с тестами и полными ситуационными задачами, а также JSON;
- сохранение исходных имён изображений в `questions.text_after` и отдельный ZIP
  с файлами в папке `images`;
- режим обновления общего банка и режим нового документа заданного размера;
- полный снимок накопленного банка в каждом экспорте и отдельный список изменений запуска в JSON;
- стабильные клиентские ID при повторных выгрузках.

## Безопасность

- пароль, введённый в интерфейсе, хранится только в памяти процесса;
- по умолчанию сбор не создаёт попытки и не отправляет ответы;
- разрешения на создание попыток и получение ключей действуют только в конкретном запуске;
- секреты, raw-данные и диагностические трассировки не попадают в клиентский экспорт;
- временные параметры подписанных URL изображений не попадают в клиентский экспорт;
- панель открывается только на `127.0.0.1`.

## Алгоритм завершения

1. Клиент указывает ориентировочное количество материалов текущего банка.
2. Программа собирает уникальные готовые материалы до достижения ориентира.
3. Затем выполняет дополнительный проверочный объём, по умолчанию 15%.
4. Повторы учитываются, но сами по себе не завершают запуск.
5. Если раньше сработал технический лимит, результат получает статус `partial`.

Без официального списка идентификаторов программа не заявляет доказанный 100% охват.

## Разработка

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python -m medik_pilot
```

Панель откроется на <http://127.0.0.1:8765>.

## Проверка

```bash
python3 -m compileall -q medik_pilot scripts
python3 -m pytest -q
python3 scripts/build-verification-sample.py
```

На Windows скрипт `scripts\build-windows.ps1` создаёт чистый клиентский архив
`release\MedikTest-Collector-Windows.zip`. В него не копируются `.env`, SQLite,
raw-данные и диагностические файлы.

Проверка готового пакета:

```powershell
.\scripts\build-windows.ps1
.\scripts\smoke-windows-package.ps1 `
  -ExePath .\r\MedikTest-Collector\MedikTest-Collector.exe
```

Скрипт сборки проверяет обязательные файлы, отсутствие секретов и рабочих данных,
безопасность и длину внутренних путей, затем создаёт SHA-256. Smoke-тест использует
только синтетический источник и не обращается к тренажёру.
