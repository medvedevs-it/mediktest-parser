# MedikTest Collector 1.0.0

Дата сборки: 29.07.2026.

## Готово

- сбор тестов и ситуационных задач по «Лечебному делу»;
- сохранение полного кейса: условие, разделы, вопросы, варианты и ключи;
- независимые ориентиры банка и проверочный запас;
- технические лимиты по попыткам, выдачам и времени;
- продолжение перебора при повторах;
- дедупликация, версии и стабильные клиентские ID;
- пауза, продолжение, мягкая остановка и восстановление после перезапуска;
- отдельные разрешения на создание и завершение попыток;
- Excel по листам `Вопросы (5137)`, `exercise_rows`, `questions`, `answers`;
- полный JSON со снимком каталога и изменениями запуска;
- локальный интерфейс и история запусков;
- Windows EXE со встроенным браузером.

## Проверка релиза

- 30 из 30 автоматических тестов прошли на macOS;
- 30 из 30 автоматических тестов прошли на Windows;
- клиентский ZIP прошёл проверку состава и безопасности;
- ZIP распакован штатным `Expand-Archive` на Windows;
- EXE запущен из распакованной архивной копии;
- демо-сценарий собрал 10 тестов и 3 целых ситуационных задачи;
- JSON и Excel из smoke-сценария содержат ожидаемое число сущностей.

Реальный тренажёр во время финального Windows smoke-теста не использовался.
Ранее отдельно разрешённые проверки подтвердили чтение 80 тестовых ключей и
полного кейса из 12 вопросов.

## Известное ограничение

Если источник не предоставляет официальный перечень ID, программа не может
математически подтвердить абсолютный 100% охват. Она показывает ориентир,
фактически найденные материалы, проверочный объём, технические лимиты и причину
остановки.
